# Поиск аномалий и система алертов в Airflow 

Задача: каждые 15 минут автоматически проверять ключевые продуктовые метрики (число лайков, просмотров, DAU и CTR) ленты приложения на аномальность. В случае нахождения аномалии отправлять в телеграм репорт с сообщением и графиком.

Реализовано несколько методов обнаружения аномалии: 
1. Прогнозирование временного ряда с помощью модели Хольта-Винтерса
Для прогнозирования следующего значения используется модель экспоненциального сглаживания с учетом тренда и сезонности.
На основе ошибки модели строится доверительный интервал.
2. Rolling Window 
Для каждой точки рассчитываются среднее значение и стандартное отклонение за предыдущие два часа.
Аномалией считается значение, выходящее за границы:
mean ± 3 × std
3. IQR - межквартильный размах 
Текущее значение сравнивается с историческими значениями за тот же 15-минутный интервал предыдущих дней.

Даг для Airflow, отправляющий сообщение в тг-бота в случае нахождения аномального значения двумя или более методами, запускается каждые 15 минут. 

При обнаружении аномалии Telegram-бот отправляет:
- название метрики;
- метод обнаружения;
- текущее значение;
- допустимый диапазон;
- график изменения метрики за последние два дня с выделенной текущей точкой.
