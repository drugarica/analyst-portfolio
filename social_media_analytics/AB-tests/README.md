# A/B-тестирование продуктовой метрики CTR

В проекте проведен анализ результатов A/B-теста после изменений в рекомендательной ленте приложения.
**Цель исследования**: определить, существует ли статистически значимое различие в CTR между контрольной и экспериментальной группами и сравнить эффективность различных методов анализа метрики.
Данные извлекались из ClickHouse с помощью SQL-запросов.

- Проведен исследовательский анализ распределений CTR
- Сравнены результаты t-теста, критерия Манна–Уитни, bootstrap, сглаженного CTR и бакетированного анализа
- Выполнена визуализация распределений и интерпретация результатов

**Результат**: сравнение методов показало, что для данной задачи bootstrap, критерий Манна–Уитни и бакетизация обнаруживают статистически значимый эффект, тогда как t-тест не выявляет различий из-за особенностей распределения метрики.
