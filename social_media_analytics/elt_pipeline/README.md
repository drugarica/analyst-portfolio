# ELT пайплайн в Airflow 

Цель:
Автоматизировать ежедневное построение витрины продуктовых метрик.

Что делает DAG?
Каждый день:
- получает данные из ленты
- получает данные мессенджера
- объединяет информацию
- рассчитывает агрегаты
- формирует итоговую таблицу
- загружает результаты в ClickHouse

Срезы
- OS
- Gender
- Age

Рассчитываемые показатели: 
views,
likes,
messages_sent,
messages_received,
users_sent,
users_received.
