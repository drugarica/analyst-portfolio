# Прогнозирование метрик с помощью Orbit

Цель: 
Спрогнозировать активность пользователей в ленте приложения на следующий месяц.
В качестве целевой переменной используется количество действий пользователей: лайки и просмотры

Используемая модель
Orbit: 
DLT
MCMC

Дополнительно введен бинарный регрессор, учитывающий периоды:
- рекламной кампании
- флешмоба
Результат: 
Получен прогноз пользовательской активности на месяц вперед с учетом внешних факторов, влияющих на поведение аудитории.
